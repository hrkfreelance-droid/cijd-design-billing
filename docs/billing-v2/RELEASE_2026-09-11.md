## Rules this release relies on

- Price `null` is "Price pending"; `0` is a price. A pending price always holds a project in progress.
- Readiness: `READY` / `IN_PROGRESS` set by hand stay where they are; `AUTO` follows production.
  Editing a ready project keeps it ready. Mark as billed re-applies a by-hand READY and refuses
  anything the board would not show as ready (`src/lib/billing-v2/mark-billed.ts`).
- Board, detail and archive totals all come from `src/lib/billing-v2/board.ts`; the printing
  price rule only from `src/lib/billing-v2/pricing.ts`.
- `override_billing_price` (SQL) refuses `0`; trusted server sessions write `$0` directly
  (`SupabaseRepository.writeBillingPrice`). A migration allowing `>= 0` would remove that branch.
